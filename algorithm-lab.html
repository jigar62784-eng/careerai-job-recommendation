PBL Academic Foundations & Algorithm Analysis

1. Breadth-First Search (BFS)

BFS systematically explores all neighbor nodes at current depth $d$ before moving to $d+1$ using a First-In-First-Out (FIFO) queue. When edges have uniform unit cost, BFS is guaranteed to discover the shortest path with the minimum number of prerequisite transitions.

Time Complexity: O(|V| + |E|)
Space Complexity: O(|V|)

2. A* Heuristic Search

A* guides exploration toward the target career role using the evaluation function f(n) = g(n) + h(n). $g(n)$ is the exact accumulated learning difficulty cost from start to $n$. $h(n)$ is the Euclidean straight-line distance in competency coordinate space. Because $h(n) \le h^*(n)$ (admissible heuristic), A* is guaranteed to return the optimal minimum-cost learning path.

Evaluation: f(n) = g(n) + h(n)
Admissibility: h(n) ≤ h*(n) [Guaranteed Optimal]
